# 🚀 Nova - Modern Responsive Website

A modern, responsive and visually appealing website template built using **HTML, CSS and JavaScript**.

🔗 **Live Demo:** https://jeffrin-nijo.github.io/demo-webpage/

---

## 📌 About The Project

**Nova** is a modern business website designed to provide a clean and professional online presence.

The website includes a responsive layout, modern UI elements, smooth animations, dark/light mode, mobile navigation, service sections, statistics and a contact form.

---

## ✨ Features

* 🚀 Modern and clean UI
* 📱 Fully responsive design
* ⚡ Fast and lightweight
* 🌙 Dark/Light mode
* 📱 Mobile-friendly navigation
* 🎨 Modern animations and hover effects
* 💻 Web Development service section
* 📱 App Development service section
* 🎯 Digital Marketing section
* 📊 Statistics section
* 📧 Contact form UI
* 🌎 Works across different screen sizes
* 💾 Theme preference saved using Local Storage

---

## 🛠️ Technologies Used

* **HTML5** - Website structure
* **CSS3** - Styling, responsive design and animations
* **JavaScript** - Interactions and functionality
* **GitHub Pages** - Website hosting

## 📱 Responsive Design

The website is designed to work on:

* 📱 Mobile phones
* 📲 Tablets
* 💻 Laptops
* 🖥️ Desktop computers

The navigation and content automatically adapt to smaller screen sizes.

---

## 🌙 Dark / Light Mode

Nova includes a theme switcher that allows users to switch between dark and light modes.

The selected theme is saved in the browser using **Local Storage**, so the preference can be remembered.

## 🚀 How To Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/jeffrin-nijo/demo-webpage.git
```

### 2. Open the project

```bash
cd demo-webpage
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for easier development.
